# v1.0.2

Первый выпуск с готовыми сборками: консольный `ctool1cd` и графический `gtool1cd`
под Linux и Windows, плюс пакет `.deb`. Отдельная сборка Qt и Boost больше не
нужна — для Linux всё нужное лежит в архиве рядом с программами.

## Работа с хранилищами расширений

- Выгрузка хранилища расширения в файл `.cfe` (хранилище определяется по
  `DEPOTVER=100`). Раньше выгружался `.cf`, Конфигуратор его как расширение
  не принимал.
- Версия выгрузки: `-drc 0` — последняя, `-drc -1` — предыдущая.
- Ключ `-nocache` (короткий `-nc`) отключает использование кэша снэпшотов
  (`cache/ddb<NNNNN>.snp`).

## Работа с одним файлом `.1CD`

- Каталог `data/` рядом с `.1CD` больше не обязателен: если тела объектов лежат
  внутри файла, выгрузка идёт из него, без каталога данных.
- Если тел объектов в файле нет — так устроены хранилища формата 8.3.8 и выше,
  где данные лежат в `data/objects` и `data/pack`, — выгрузка завершается
  понятным сообщением: таблица, объект, версия, причина и что делать
  («выгружать из полной копии хранилища»). Никакого «успеха» с пустым файлом.

## Исправления

- При ошибках утилита возвращает ненулевой код возврата (206), а не 0 — это
  ломало автоматизацию, которая считала сбой успехом.
- Недописанный файл при сбое удаляется, а не остаётся обрубком.
- Содержимое снэпшота больше не отдаётся вместо файла конфигурации.
- Версия печатается в справке утилиты (`ctool1cd -h`).
- Сборка на Linux: статический Boost больше не требуется.
- Тесты записи формата 8.3.8 не падают, когда каталог исходников и каталог
  временных файлов лежат на разных устройствах.

## Готовые сборки

- **Linux x86_64** — `tool1cd-1.0.2-linux-x86_64.tar.gz`, собран на Debian 12
  (glibc 2.36): Qt и остальные библиотеки внутри, распаковать и запускать.
- **Windows x64** — `tool1cd-1.0.2-win64.zip`, MSYS2 UCRT64, зависимости внутри.
- **Debian/Ubuntu** — `tool1cd_1.0.2_amd64.deb`: ставится в `/opt/tool1cd`,
  команды `ctool1cd` и `gtool1cd` появляются в `PATH`.

## Ограничения

- Для хранилищ формата 8.3.8 и выше (в том числе для хранилищ расширений) нужна
  вся папка хранилища — файл `.1CD` вместе с каталогом `data`. Из одного файла
  такие хранилища не выгружаются: тел объектов в нём нет.
- Утилита открывает базу в режиме редактирования, поэтому работайте с копией
  хранилища, а не с рабочим.
- Приёмка выгрузки — загрузка результата в Конфигуратор: контейнеры `.cf`/`.cfe`
  содержат внутри время выгрузки, поэтому побайтовое сравнение двух выгрузок
  ничего не доказывает.

## Проверено

- 119 утверждений в 29 наборах тестов (Linux).
- Выгрузка хранилища расширения: 373 файла, содержимое совпадает с эталоном,
  выгруженным Конфигуратором.
- Замыкание зависимостей в архивах проверяется на упаковке: сборка не выйдет в
  релиз, если какой-то библиотеки не хватает.
