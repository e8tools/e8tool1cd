## Изменения

Исправлена выгрузка из хранилища на Windows: обрыв с ошибкой `Wrong offset`.

### `Wrong offset` при выгрузке (#3)

Конструктор `TFileStream` игнорировал переданный режим и **всегда** открывал
файл в режиме `in|out`, то есть требовал прав на запись. На Windows это
отказывает, если файл

- только для чтения (атрибут R, сетевой ресурс, CD, права NTFS), или
- занят другим процессом (Конфигуратор, сервер 1С, антивирус).

Открытие не удаётся, размер потока остаётся нулевым, и первое же обращение
к индексу `data/pack/*.ind` даёт `Wrong offset` — выгрузка обрывалась сразу
после открытия базы, файл расширения не создавался.

Теперь `fmOpenRead` открывает файл только на чтение, `fmCreate` — на запись
с усечением, остальные режимы — на чтение и запись, как раньше. На Linux
поведение не меняется.

Если выгрузка всё же обрывается, проверьте права и занятость файлов:

```
attrib -R E:\repository\spec\data\pack\*.*
```

и убедитесь, что хранилище не открыто в Конфигураторе.
