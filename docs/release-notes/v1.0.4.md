## Изменения

Исправлен вывод кириллицы в консоль Windows.

### Кириллица при запуске в Windows (#2)

Строки в программе хранятся в UTF-8, а консоль Windows работает в своей
кодовой странице (обычно cp866). Прямая запись байтов UTF-8 через `cout`/`cerr`
показывала вместо кириллицы нечитаемые символы — при запуске без аргументов это
было видно на подсказке «Запусти cTool_1CD -h для справки».

Добавлен `ConsoleOutput`: на Windows текст уходит в консоль через `WriteConsoleW`
широкими символами, минуя кодовую страницу. При перенаправленном выводе
(в файл или канал) пишутся байты UTF-8, как и раньше — лог-файл и каналы
не меняются.
